This was a cool vibe coded website to test out the different api's that the MTA (Metropolitan Transit Authority),
Offered to the public for real time data.

I thought it would be cool to create a quick projected based of the real time and the mta app for real time train timings,
but in the format of you waiting inside a subway platform. 

Feel free to clone the app and make your own changes!
